Use ImageSquish safely from an AI agent.

This page describes the real imgsquish CLI and the project Skill. It is documentation only. Opening or reading this page never runs a command and never changes a file.

Before doing anything

If the user's goal is unclear, ask whether they want the reusable Claude Code Skill or a one-off npx run. If the user already gave concrete files and a clear image operation, do not ask that extra choice. Ask only for missing paths or settings. Respond in the user's language.

What ImageSquish does

ImageSquish compresses and resizes JPEG, PNG, and WebP images locally. It can keep the input format, convert formats, or fit an output under a byte limit.

Two ways to use it

Reusable Skill

Install or keep this repository Skill at .claude/skills/imgsquish/SKILL.md when the user wants repeated Claude Code use.

One-off npx

Run npx imgsquish for a single request when no reusable Skill is needed.

CLI contract

npx imgsquish [options] <files|globs|folders...>
Inputs
Single files, multiple files, globs, or folders. Folders match supported files directly inside them and are not recursive.
Input extensions
.jpg, .jpeg, .png, and .webp.
Defaults
Preset balanced, output beside each input, input format preserved, suffix -min, metadata removed.
Options
-h/--help, --list-presets, --list-targets, -p/--preset, -q/--quality, -f/--format, -m/--max, -s/--max-size, -o/--out, --suffix, --keep-metadata, --lossless, --dry-run.

Important behavior

  • --format supports keep, jpeg, jpg, png, and webp. jpg becomes JPEG.
  • --max-size accepts a size such as 500KB or a target ID from --list-targets.
  • --keep-metadata preserves metadata. It is removed by default.
  • --lossless requests lossless WebP output.
  • --dry-run performs compression calculations but skips file writes.
  • Existing output files can be overwritten.
  • Multiple files run sequentially. Any failed file makes the final exit code 1.

Examples

npx imgsquish photo.jpg
npx imgsquish ./images -o ./images-min
npx imgsquish -p small "shots/*.png"
npx imgsquish -q 70 -m 1600 hero.jpg
npx imgsquish --max-size 10MB clip.png
npx imgsquish -s github-avatar -m 500 me.png
npx imgsquish --dry-run ./images
