ImageSquish AI instructions

This is an instruction page for AI agents. Reading this page alone must not run commands, inspect files, install a Skill, or modify files. Respond in the user's language.

Required behavior

  1. If the user only asks what ImageSquish is or asks to read this page, explain it and do not process files.
  2. If the user wants image processing but has not chosen a reusable Skill or a one-off run, ask which they want before acting.
  3. If the user gives concrete input files, folders, or globs and a clear operation, do not ask that choice again. Use the CLI rules below.
  4. If paths, formats, presets, targets, or requested settings are unclear, ask only for the missing information.
  5. Do not invent CLI options, formats, presets, targets, or recursive behavior.

Available methods

Reusable Claude Code Skill
Install or use .claude/skills/imgsquish/SKILL.md when the user wants repeated support.
One-off CLI
Use npx imgsquish [options] <files|globs|folders...> for a single request.

CLI contract

Inputs
Single files, multiple files, globs, or folders. A folder matches supported files directly inside it and is not recursive.
Input extensions
.jpg, .jpeg, .png, .webp.
Defaults
Preset balanced, output beside each input, input format preserved, suffix -min, metadata removed.
Options
-h/--help, --list-presets, --list-targets, -p/--preset, -q/--quality, -f/--format, -m/--max, -s/--max-size, -o/--out, --suffix, --keep-metadata, --lossless, --dry-run.

Safety

  • --dry-run performs compression calculations but skips file writes.
  • Existing output files can be overwritten.
  • Metadata is removed by default. Use --keep-metadata only when requested.
  • Multiple files are processed sequentially. Any failed file makes the final exit code 1.
  • Use --list-presets or --list-targets when the requested value is unknown.

Read https://imgsquish.riyo.me/ai, follow its instructions, and handle my request.
